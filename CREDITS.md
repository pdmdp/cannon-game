I used AI tools during development for debugging, code review, implementation
support, identifying gameplay paths and edge cases for testing, and help with

I prepared the image prompts in a GPT-5.5 conversation and generated the
illustrations with ChatGPT Images 2.0.

## Soundtrack

I generated the ten soundtrack tracks with Gemini 3.1 Pro.

## Sound effects

The sound effects and fallback music loop were generated procedurally by a
Python script used during development. The generated WAV files are included
with the game.
